# Jahe Padjajaran Website

A premium digital experience crafted to introduce Jahe Padjajaran — a modern interpretation of traditional Indonesian ginger-based products. This website is designed not just to inform, but to connect, engage, and convert visitors into customers and partners.

---

About the Brand

Jahe Padjajaran represents the richness of Indonesian heritage through high-quality ginger products. Rooted in tradition and elevated with modern presentation, the brand aims to deliver both authenticity and excellence.

This website serves as a digital gateway to:
- Discover the story behind the brand
- Explore product offerings
- Experience the visual identity of Jahe Padjajaran
- Connect directly for business opportunities

---

Technology Behind the Experience

This website is built using modern web technologies to ensure performance, scalability, and maintainability:

- React – Component-based UI development
- Vite – Fast build tool for modern frontend workflows
- Tailwind CSS – Utility-first styling for consistent design
- Framer Motion – Smooth and engaging animations
- Context API – Lightweight state management
